# Politique de confidentialité — Zap Remote

Dernière mise à jour : novembre 2026.

Zap Remote ne collecte, ne transmet et ne vend **aucune donnée personnelle**.

- Aucun compte, aucune publicité, aucun outil d'analyse ou de suivi.
- L'application communique uniquement avec les téléviseurs de votre réseau local (Wi-Fi) ou par infrarouge.
- Les informations nécessaires pour se reconnecter (nom et adresse IP des TV, jetons d'appairage, certificat client)
  sont stockées uniquement sur votre téléphone, dans l'espace privé de l'application, et supprimées
  avec elle.

Permissions utilisées : accès réseau et Wi-Fi (contrôler et détecter les TV), multicast (détection),
infrarouge (téléphones équipés d'un émetteur IR).

Contact : via les issues du dépôt GitHub du projet.
